# Weeb Terebi

Каталог онгоингов Anime 365 для телевизора Samsung с Tizen 5.5.
Electron открывает тот же бандл, который устанавливается на телевизор.

Поместите `ACCESS_TOKEN=...` в файл `.env` в корне проекта. При сборке токен попадёт в локальный виджет.

```sh
mise install
mise run app:install
mise run electron:install
mise run electron
```

Команда `mise run tv:install` собирает виджет и запускает его на телевизоре по адресу из `app/package.json`. Отдельная сборка — `mise run build`, результат — `app/dist/weebterebi.wgt`. Проверка Biome — `mise run lint`, форматирование — `mise run format`. Сборка также проверяет типы.

Стрелки перемещают фокус. Влево с первой колонки открывает меню, вправо из меню возвращает к прежней карточке. OK открывает карточку со списком серий. Выберите серию, затем озвучку или субтитры, чтобы начать просмотр. Стрелки вверх и вниз перемещают фокус в списках.

В плеере OK или Play/Pause переключает паузу, стрелки влево и вправо перематывают на 10 секунд. Return на пульте или Escape в Electron возвращает к выбранному переводу. Следующие нажатия возвращают к серии и к постеру. MP4 воспроизводит встроенный HTML5-плеер, отдельные ASS-субтитры отображает Jellyfin libass.
